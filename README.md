# 千岛湖渔业溯源系统 V1.1.4

## 原型说明

本仓库为千岛湖渔业溯源系统 V1.1.4 版本的交互原型（单文件，零外部依赖）。

- **主文件**：`溯源管理_三单改造原型_V1.1.4.html`
- 双击用浏览器打开即可预览，无需任何服务器或网络依赖。

## 本版本主要内容

V1.1.4 覆盖陆基养殖户「溯源码申请 → 协会审批 → 捕捞绑码」全链路改造：

- 溯源码申请：选择养殖池 + 预计出售时间 + 出售数量，提交生成一张溯源码申请单（AQ 编号）
- 溯源码审批：通过/驳回收进详情页，列表含计划出售、实际使用
- 捕捞记录：关联溯源码申请发起，捕捞数量=码段合计，支持多码段、产品名称、捕捞数量（斤）、养殖池清空、检测报告、现场图片、保存草稿
- 记录审核、协会监管：新增功能
- 养殖户小程序捕捞记录：对齐 PC 三单新流程
